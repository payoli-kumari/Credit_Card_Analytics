Project Scope & Purpose

What is This Project About?

A simple breakdown of why this project was created and what problems it solves.

The Business Context

A major credit card provider wanted to closely monitor daily and weekly performance across transactions and customer groups. Prior to this project, reporting was manual and fragmented.

  • Goal 1: Weekly Performance Tracking — Monitor revenue, transaction volume, and interest earned every week seamlessly.
  • Goal 2: Customer Profiling — Understand which age groups, income levels, and job categories generate the highest card revenue.
  • Goal 3: Channel Analysis — Compare spending across Swipe, Chip, and Online transactions to guide marketing strategies.

How The Data Pipeline Works

Raw CSV data is loaded into PostgreSQL/SQL database tables, cleaned with Power Query, modeled using a Star Schema in Power BI, and transformed into two main interactive dashboards.

Executive Takeaways

Key Business Insights Discovered

Core findings derived from combining customer demographic data with transaction details.

1. Blue Card Dominance

The Blue Card category generates $46.1M (83.4%) of total revenue and $6.5M in interest earned, making it the foundation of the portfolio.

2. Swipe vs Online Usage

In-person Swipe transactions dominate at $35M revenue, while Chip generates $17M. Online spending ($3M) remains a key area for digital growth.

3. High-Value Customer Profile

Customers with a Graduate degree contribute $22M revenue, and Businessmen ($17M) are the highest spending job segment.

4. Top 3 Revenue States

Texas (TX), New York (NY), and California (CA) contribute $39M combined (over 70% of total customer revenue).

5. Quarterly Performance

Revenue remains remarkably stable across quarters: Q1 ($14.0M), Q2 ($13.8M), Q3 ($14.2M), and Q4 ($13.3M), with Q3 logging the highest transaction volume (166.6K).

6. Core Expenditure Types

Bill payments ($14M), Entertainment ($10M), Fuel ($9M), and Groceries ($9M) represent the top four spending drivers.

Technical Formulas

DAX Formulas & SQL Queries Used

The exact DAX formulas and SQL queries used to create calculations, measures, and data feeds in Power BI.

-- ===================================================
-- DAX FORMULAS USED IN THIS POWER BI PROJECT
-- ===================================================

-- 1. Calculated Column: Age Group Classification
AgeGroup = 
SWITCH(
    TRUE(),
    'customer'[Customer_Age] < 30, "20-30",
    'customer'[Customer_Age] >= 30 && 'customer'[Customer_Age] < 40, "30-40",
    'customer'[Customer_Age] >= 40 && 'customer'[Customer_Age] < 50, "40-50",
    'customer'[Customer_Age] >= 50 && 'customer'[Customer_Age] < 60, "50-60",
    'customer'[Customer_Age] >= 60, "60+",
    "Unknown"
)

-- 2. Calculated Column: Income Group Classification
IncomeGroup = 
SWITCH(
    TRUE(),
    'customer'[Income] < 35000, "Low",
    'customer'[Income] >= 35000 && 'customer'[Income] < 70000, "Med",
    'customer'[Income] >= 70000, "High",
    "Unknown"
)

-- 3. Measure: Total Revenue
Total_Revenue = 
SUM('credit_card'[Total_Trans_Amt]) + SUM('credit_card'[Annual_Fees]) + SUM('credit_card'[Interest_Earned])

-- 4. Measure: Current Week Revenue
Current_Week_Revenue = 
VAR MaxWeek = MAX('credit_card'[Week_Num])
RETURN 
CALCULATE(
    [Total_Revenue],
    'credit_card'[Week_Num] = MaxWeek
)

-- 5. Measure: Previous Week Revenue
Previous_Week_Revenue = 
CALCULATE(
    [Total_Revenue],
    'credit_card'[Week_Num] = MAX('credit_card'[Week_Num]) - 1
)

-- 6. Measure: Week-on-Week (WoW) Revenue Growth (%)
WoW_Revenue_Growth = 
VAR CurrentWeek = [Current_Week_Revenue]
VAR PreviousWeek = [Previous_Week_Revenue]
RETURN 
DIVIDE(CurrentWeek - PreviousWeek, PreviousWeek, 0)
-- ===================================================
-- SQL STATEMENTS USED FOR DATA PIPELINE & INGESTION
-- ===================================================

-- 1. Create Credit Card Detail Table
CREATE TABLE credit_card_detail (
    Client_Num INT,
    Card_Category VARCHAR(20),
    Annual_Fees INT,
    Activation_30_Days INT,
    Customer_Acq_Cost INT,
    Week_Start_Date DATE,
    Week_Num VARCHAR(20),
    Qtr VARCHAR(10),
    current_year INT,
    Credit_Limit DECIMAL(10,2),
    Total_Revolving_Bal INT,
    Total_Trans_Amt INT,
    Total_Trans_Vol INT,
    Avg_Utilization_Ratio DECIMAL(10,3),
    Use_Chip VARCHAR(10),
    Exp_Type VARCHAR(50),
    Interest_Earned DECIMAL(10,2),
    Delinquent_Acc INT
);

-- 2. Create Customer Detail Table
CREATE TABLE customer_detail (
    Client_Num INT,
    Customer_Age INT,
    Gender VARCHAR(5),
    Dependent_Count INT,
    Education_Level VARCHAR(50),
    Marital_Status VARCHAR(20),
    state_cd VARCHAR(10),
    Zipcode INT,
    Car_Owner VARCHAR(5),
    House_Owner VARCHAR(5),
    Personal_loan VARCHAR(5),
    contact VARCHAR(50),
    Customer_Job VARCHAR(50),
    Income INT,
    Cust_Satisfaction_Score INT
);

-- 3. Data Import Statements
COPY credit_card_detail FROM 'credit_card.csv' DELIMITER ',' CSV HEADER;
COPY customer_detail FROM 'customer.csv' DELIMITER ',' CSV HEADER;

-- 4. Weekly Additional Data Ingestion
COPY credit_card_detail FROM 'cc_add.csv' DELIMITER ',' CSV HEADER;
COPY customer_detail FROM 'cust_add.csv' DELIMITER ',' CSV HEADER;
Data Architecture

Dataset & File Structure

The project uses 4 CSV files joined into a Star Schema model in Power BI.

credit_card.csv & cc_add.csv

Transaction Feeds

Stores transaction facts including transaction amounts, annual fees, credit limits, revolving balances, interest earned, and payment channels.

Key Fields: Client_Num, Card_Category, Week_Start_Date, Total_Trans_Amt, Use Chip, Exp Type, Interest_Earned.

customer.csv & cust_add.csv

Customer Dimension Feeds

Stores customer profiles including age, gender, education level, marital status, state location, job profile, income, and satisfaction scores.

Key Fields: Client_Num, Customer_Age, Gender, Education_Level, Marital_Status, state_cd, Income, Cust_Satisfaction_Score.
